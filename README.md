# Pentest & Security Notes
A living, structured repository documenting my ongoing journey, technical research, and field notes in offensive security. All notes are organized strictly around the core methodology of hacking—continuously updated as I learn, test, and break things.Feel free to clone, fork, and study the materials for your own learning path!
# Core Methodology Structure
The notes in this repository are categorized according to standard penetration testing phases and specialized focus areas:
├── 01-Reconnaissance/       # OSINT, active/passive discovery, fingerprinting
├── 02-Enumeration/          # Service scanning, directory busting, deep probing
├── 03-Vulnerability-Analysis/ # Identifying flaws, misconfigurations, and logic gaps
├── 04-Exploitation/         # Weaponization, payload delivery, and proof-of-concepts
├── 05-Post-Exploitation/    # Persistence, pivoting, and lateral movement
└── 06-Specialized-Focus/    # Web Application & IoT Security deep-dives
# Focus Areas
Web Application Security: Vulnerability breakdowns, payload design, OWASP Top 10 deep dives, and academy lab notes.Internet of Things (IoT) Security: Firmware analysis notes, hardware hacking techniques, and embedded interface evaluations.Reconnaissance & OSINT: Information gathering playbooks, automation scripts, and target mapping strategies.
